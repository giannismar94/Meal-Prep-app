# 🦋 Πεταλούδα

Web app διατροφής για απώλεια βάρους, με τη Λίλα την πεταλούδα. Φτιαγμένη για κινητό.

- Υπολογίζει θερμίδες, πρωτεΐνη και νερό από ηλικία, ύψος, βάρος, στόχο και ρυθμό
- Προτείνει γεύματα για κάθε μέρα με ζυγισμένες ποσότητες, προσαρμοσμένες στον στόχο
- Αλλαγή πρότασης (↻) ή επιλογή από λίστα, αγαπημένα ♥, «δεν μου αρέσει», δικά της γεύματα
- Νερό με ποτήρια, κίνηση ημέρας με βήματα, εβδομαδιαίο πρόγραμμα
- Ημερήσιοι στόχοι (κάποιοι τσεκάρονται αυτόματα), ιστορικό 14 ημερών
- Ζυγίσματα με γράφημα, μέσος όρος εβδομάδας
- Η Λίλα μαζεύει 🦋 από κάθε στόχο και μεταμορφώνεται: κάμπια → κουκούλι → πεταλούδα → λαμπερή πεταλούδα
- Όλα τα δεδομένα μένουν **μόνο στη συσκευή** (localStorage). Κανένας server, κανένας λογαριασμός.
- Δουλεύει και offline (service worker)

## Ανέβασμα στο GitHub Pages

1. Φτιάξε νέο **public** repo, π.χ. `petalouda`.
2. Ανέβασε όλα τα αρχεία έτσι ώστε το `index.html` να είναι στη ρίζα του repo (μαζί με τον φάκελο `icons/`).
3. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, φάκελος `/ (root)` → Save.
4. Σε 1-2 λεπτά ανοίγει στο `https://<username>.github.io/petalouda/`.

Από γραμμή εντολών:

```bash
cd petalouda
git init && git add . && git commit -m "Πεταλούδα 🦋"
git branch -M main
git remote add origin https://github.com/<username>/petalouda.git
git push -u origin main
```

## Εγκατάσταση στο κινητό

**iPhone:** άνοιξε το link στο **Safari** → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».
**Android:** άνοιξε το link στο **Chrome** → ⋮ → «Προσθήκη στην αρχική οθόνη» / «Εγκατάσταση εφαρμογής».

Στο iPhone είναι σημαντικό να ανοίγει από το εικονίδιο της αρχικής οθόνης: το Safari μπορεί να σβήσει δεδομένα ιστοσελίδων που δεν έχουν ανοιχτεί για μέρες, ενώ οι εφαρμογές της αρχικής οθόνης εξαιρούνται.

## Δεδομένα

- Αποθηκεύονται στο `localStorage` με κλειδί `petalouda_v1`. Κάθε συσκευή και κάθε browser έχει τα δικά του, ξεχωριστά.
- Όλα τα project στο `<username>.github.io` μοιράζονται το ίδιο origin, οπότε το μοναδικό κλειδί κρατάει τα δεδομένα χωριστά από άλλες εφαρμογές σου εκεί.
- **Ρυθμίσεις (⚙) → Αντίγραφο ↓** κατεβάζει/μοιράζεται ένα `.json`. **Επαναφορά ↑** το φέρνει πίσω (π.χ. σε νέο κινητό).

## Ενημερώσεις

Όταν αλλάζεις κάτι, ανέβασε τον αριθμό στη γραμμή `const CACHE = 'petalouda-v1'` του `sw.js` (σε `v2`, `v3`…) ώστε να φορτώσει η νέα έκδοση. Τα δεδομένα δεν επηρεάζονται.

Τα γεύματα (`MEALS`), τα τρόφιμα (`F`) και οι ασκήσεις (`W`) είναι στην αρχή του `<script>` στο `index.html` και αλλάζουν εύκολα.

> Οι θερμίδες είναι εκτιμήσεις (Mifflin-St Jeor). Η εφαρμογή δεν αντικαθιστά γιατρό ή διαιτολόγο. Δεν κατεβαίνει κάτω από 1.200 kcal για γυναίκες / 1.500 για άνδρες και δεν δέχεται στόχο κάτω από υγιές BMI.
